Кароч, ребятки, вот как с этим работать. В общем всё это в папку для сайтов, по типу где вы хостите.
Есть файл так же "opensource_multverse.sql". Это пустые таблицы со стороны MySQLi. Её вы импортируете в базу данных свою через phpMyAdmin.
Зайдите в папку php, потом откройте файл db.php. Туда введите адрес сервера, имя, пароль от sql и название базы данных.
